### Key Parameters Explained (bpf_jit_harden)
<p>
  <ul> The bpf_jit_harden value has the following options:
    <li> 0: Disables JIT hardening1 Enables JIT hardening for unprivileged users only. </li>
    <li> 2: Enables JIT hardening for all users. </li>
    <br>
   NOTE: 2 is the standard benchmark required by security baselines such as the DISA STIG to mitigate JIT Spraying attacks across the entire operating system.

  </ul>
</p>
